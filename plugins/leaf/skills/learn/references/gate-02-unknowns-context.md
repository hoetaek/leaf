# ② Unknowns & Context

**What ② builds: you understand the topic well enough to judge it for
yourself, and the fact/assumption boundary is visible.** Learn-close locks
the why / what / wireframe triple.

Name what is missing before searching. Then answer those entries in the same
file: write the question, find the answer, update the entry with what was
found and its source.

Gate to continue:

- Blocking unknowns are separated from useful-later ones, and each blocking
  unknown has a sourced answer, an explicit assumption, or a user question.
- The fact/assumption boundary is visible: the premises each key judgment
  leans on are surfaced, each with a source or a cheap verification path.
- No load-bearing ASSUMPTION rests silent: each is resolved, escalated for
  user review, or recorded with what would be believed instead if false.
- Any change from ①'s provisional what is recorded with the fact or premise
  that caused it.
- The user can explain the core knowledge the topic's decisions rest on —
  the concepts, why it is this way, and where it forks.
- The why / what / wireframe triple is locked in `00-status.md` through an
  ask → approve → write loop — per item for discovery-heavy, or as one
  unambiguous bundle for fast-track — and is never agent-authored;
  `none — <reason>` is a valid approved answer.

Helpful defaults — the scout fan-out, reading map, and closing quiz live in
the `learn` skill; deep-research rules in `research-quality.md`; the premise
table format in `../../work/references/patterns.md`. They are defaults,
never pass/fail conditions.

Fast-track procedure defaults live in
`../../using-leaf/references/fast-track.md`. A bounded unknown may spend one
scout without widening the triple. A core unknown that could change the triple,
safety, or authority exits fast-track before the lock.

Adding a check to a gate requires recording, next to it, the actual failure
it prevents. Promoting a default into a pass/fail condition counts as
adding a check.

Return here whenever a new unknown surfaces or later work overturns a prior
assumption. `01-Learn/02-unknowns.md` evolves throughout.
